# Citation Claude Friction Log

Codex-only notes for friction observed while supervising Claude citation runs in the external workbench. Keep entries short and actionable; prefer wording changes to new process unless a repeated failure needs tooling.

## Implemented Instruction Tweaks

- 2026-06-02: Added a six-section pre-article-wide gate to Claude-visible workbench docs. Full runs must produce checked outputs for `summary`, `pharmacology`, `tolerance`, `harm_potential`, `history_culture`, and `legality`; missing `legality` is a blocker, not a late optional worker. Superseded by the 2026-06-03 warning-only rule below.
- 2026-06-03: Relaxed the six-section status gate after PCP review. Missing citable section outputs now produce warnings and preserve the original section exactly instead of blocking the run; invalid section outputs, public markers without supported evidence, and marker-only text rewrites remain hard failures.
- 2026-06-02: Added a post-section repair gate for quote ellipses, discovery-only wiki/community support, public markers without supported evidence, and marker path mismatches before article-wide assembly or final handoff.
- 2026-06-02: Added an article-wide zero-output guard. If accepted section work exists, `article-wide.json` with empty `markedSections`, `references`, and `evidence` is failed and must be repaired or rerun.
- 2026-06-02: Added page-specific reference/source ID guidance for repeated same-site sources, especially DailyMed labels using setid, label name, or another page-specific suffix.
- 2026-06-02: Mirrored the workflow reminders in repo docs and Codex's local `cite` skill so supervision and Claude-facing prompts now describe the same gates.
- 2026-06-03: Added a compact recurring-friction checklist across Claude/Codex docs: six-row section status table, immediate article-wide non-empty inspection, uninterrupted finish sequence, stricter post-section scan list, section-shape preservation, and progress/timestamp checks for long legality or rebuild phases.
