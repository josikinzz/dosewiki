# Ralph Loop Command

Copy and paste this single-line command:

```
/ralph-loop:ralph-loop Run /missing-tables in loop mode. For each unchecked substance: deploy Explore agents to review sources, consolidate with confidence levels. NO DATA = mark reviewed and continue. HIGH confidence = auto-write to parsed-sources.json and continue. LOW/MEDIUM confidence = pause for user. Update tracker after each. Output SUBSTANCE_COMPLETE per item. When done output promise tag. --completion-promise "ALL_COMPLETE" --max-iterations 250
```

## Notes

- The prompt must be on a single line (no line breaks)
- Special characters like arrows and pipes can cause issues
- Keep it concise - Claude will understand the intent
