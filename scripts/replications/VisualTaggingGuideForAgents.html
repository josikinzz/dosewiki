Replication operations · visual evidence

Tag the perceptual mechanism, not the aesthetic.

This field guide converts Josie’s 247 reviewed notes into a repeatable inspection process for images, GIFs, and videos.

First gate: viewing mode

Decide whether the work alters a visible external world or depicts an imagined environment.

Second gate: evidence

Add an effect only when the media shows its defining mechanism.

!
This is not a skill package.

Do not copy it into a skills directory. Do not create a SKILL.md from it without a new user request.

01 · Deterministic pass

Use the same order for every replication.

The order prevents a vivid style, title, artist, or existing tag from anchoring the decision.

01

Bind the identity

Record the stable replication ID, slug, artist, media type, and current tags.

Complete whenThe ID resolves once and the live slug matches.
02

Inspect without the labels

View the image at full resolution. Play the complete video once before seeking.

Complete whenYou can describe what changes without naming an effect.
03

Choose the viewing mode

Classify the work as open-eye, closed-eye, immersive, mixed, or uncertain.

Complete whenYou can identify the external substrate or explain why none exists.
04

Build a video storyboard

Start at 15%, 40%, 60%, and 85%. Add enough frames to represent every phase.

Complete whenEvery distinct visual phase appears in the evidence.
05

Probe and hear the audio

Confirm whether an audio stream exists. Listen before choosing distortion or hallucination.

Complete whenYou can state whether sound transforms a source or introduces an imagined sound.
06

Test effect candidates

For each candidate, record the visible requirement and the closest rejected alternative.

Complete whenEvery proposed tag survives its confusion check.
07

Separate other edits

Keep artist credit, substance showcase, rights, deletion, and dating notes outside effect tags.

Complete whenEach proposal targets one database surface.
08

Return an ID-keyed proposal

Use additive, removal, or explicit set semantics. Include uncertainty and supporting frames.

Complete whenA later agent can recheck every change without guessing.
02 · Primary classification

Open-eye and closed-eye effects use different evidence.

The visual style does not determine the mode. The relationship to an external scene does.

External substrate visible

Open-eye

  • A room, road, tree, wall, face, or object remains identifiable.
  • The effect changes that existing substrate.
  • Drifting, environmental patterning, and colour shifting can apply.
  • Transformations require one external object becoming another.
example: autumn-trees-symmetric-vision
Imagined environment

Closed-eye

  • The work depicts a self-contained hallucinatory field or environment.
  • Geometry can fill the entire field without an external substrate.
  • Internal hallucination can apply to a complete imagined scene.
  • Do not infer open-eye distortions from animation alone.
example: infinite-torus-space-symmetric-vision
✓
Mixed media needs phase-level evidence.

A video can move from an external scene into an imagined environment. Record the transition before combining both families.

03 · Temporal inspection

One thumbnail cannot represent a video.

Spread frames across time, inspect transitions, and hear the audio. A title card and a climax frame are not the whole sequence.

15%
40%
60%
85%

Frame coverage

  • Use 15%, 40%, 60%, and 85% as anchor frames.
  • Use at least 12 spread frames for short, changing clips.
  • Add scene-cut frames and the first and last meaningful frames.
  • Use the full frame. Do not crop away the substrate.

Temporal threshold

  • Play the full video once at normal speed.
  • Replay suspicious intervals slowly with adjacent frames.
  • Tag a brief phase only when it is clear and material.
  • Record the time range for disputed effects.

Audio evidence

  • An audio stream is evidence to inspect, not a tag.
  • Changed environmental sound supports auditory distortion.
  • Imagined or introduced sound supports auditory hallucination.
  • Phosform has an explicit reviewer prior. Confirm each file.

GIFs and loops

  • Inspect one complete loop and its boundary.
  • Sample the loop at four evenly spaced points.
  • Check whether recursion is real or only the loop itself.
  • A looping file does not automatically depict recursion.
frame-strip recipe
# 1. Probe duration and audio streams.
ffprobe -v error -show_entries format=duration -show_streams -of json INPUT.mp4

# 2. Convert the four anchors and any added samples into timestamps.
# 3. Extract one full-frame image at each timestamp.
ffmpeg -ss TIMESTAMP -i INPUT.mp4 -frames:v 1 -vf "scale=960:-2" FRAME.jpg

# 4. For a changing short clip, build at least 12 spread frames.
# 5. Keep frame names tied to the stable replication ID.
#    <replication-id>--15.jpg, --40.jpg, --60.jpg, --85.jpg
04 · Failure atlas

Most errors occur between neighboring concepts.

Use these comparisons before adding the less common or more specific tag.

Geometry · patterning · repetition

Ask what owns the pattern.

  • Geometry: independent forms or a field of forms.
  • Environmental patterning: the original texture becomes geometry.
  • Symmetrical repetition: one external texture mirrors across itself.
  • Reject repetition for static symmetry or closed-eye mandalas.
Drifting · transformation · twisting

Track what changes.

  • Drifting: a surface warps, melts, or breathes across itself.
  • Transformation: an external object becomes another object.
  • Twisting: the visual field curls around a center.
  • Reject transformation for surreal imagery that never morphs.
Colour family

Separate intensity, cycle, loss, and offset.

  • Enhancement: colours become brighter or more vivid.
  • Shifting: an external object cycles through colours.
  • Suppression: colours become darker or less saturated.
  • Chromatic aberration: RGB-like layers split spatially.
Haze · acuity suppression

Blur is not smoke.

  • Visual haze: the air appears filled with smoke, fog, or haze.
  • Acuity suppression: detail and edges lose clarity.
  • Reject haze for blur without a suspended atmospheric layer.
  • Notes 219 and 237 remove haze from blurred videos.
Geometry · internal scene · setting

Abstract enclosure is still geometry.

  • Geometry: abstract forms fill the field without a figurative scene.
  • Internal hallucination: an imagined figurative scene or sequence appears.
  • Settings: a recognizable place contains the hallucination.
  • Reject settings for abstract tunnels, voids, patterns, and geometric chambers.
Perspective · magnification

Reserve both for actual spatial change.

  • Perspective distortion: size or distance relationships change.
  • Magnification: distant detail appears closer and enlarged.
  • Reject perspective for camera motion, zoom, or ordinary warping.
  • Notes 23, 184, and 188 mark common overuse.
After-images · tracers · recursion

Find the persistence mechanism.

  • After-images: an image remains after its source disappears.
  • Tracers: a moving object leaves a continuous trail.
  • Recursion: a scene repeats inside itself.
  • Reject recursion for ordinary looping playback.
Machinescapes · mechanical motifs

Demand a mechanical landscape.

  • Machinescapes: a vast hallucinatory mechanical environment.
  • Reject it for one machine, circuitry, or biomechanical decoration.
  • Reject it when geometry or settings explain the work.
  • Notes 128, 166, 183, and 230 correct this error.
!
Titles are discovery clues, not effect evidence.

“Entity,” “machine,” “face,” “forest,” and “wall” do not establish the matching effects.

05 · Effect reference

Require a visible mechanism for every tag.

The summaries reflect the current production effect vocabulary and Josie’s reviewed corrections.

geometry · Geometry

Use whenPatterns, form constants, shapes, or fractals materially occupy the visual field.

Do not use whenA work is merely ornate, symmetrical, psychedelic, or brightly coloured.

drifting · Drifting

Use whenAn existing object or scene progressively warps, melts, breathes, or morphs across itself.

Do not use whenOnly the camera moves, the object translates, or an abstract animation changes frames.

environmental-patterning · Environmental patterning

Use whenCarpet, clouds, foliage, stone, or another visible texture becomes geometry made from its original material.

Do not use whenIndependent geometry overlays a scene or a closed-eye pattern has no external substrate.

symmetrical-texture-repetition · Symmetrical texture repetition

Use whenAn external texture mirrors repeatedly across its own surface.

Do not use whenA static artwork is symmetrical, kaleidoscopic, tiled, or a closed-eye mandala.

internal-hallucination · Internal hallucination

Use whenThe work depicts an imagined figurative scene or sequence that is not anchored to the external world.

Do not use whenThe work is only abstract geometry, or an external scene remains the substrate.

Immersive · Viewing mode, not an effect tag

Use whenThe hallucination appears to surround or replace the viewer’s perceptual field.

Do not storeimmersive-hallucinations is not a current production effect slug. Record viewingMode: immersive in review evidence.

autonomous-entity · Autonomous entity

Use whenA being is presented as sentient, agentic, or encountered. Authorial intent can support borderline visual evidence.

Do not use whenThe media contains only a face, figure, animal, title, or decorative character.

settings-sceneries-and-landscapes · Settings, sceneries, and landscapes

Use whenA somewhat figurative, recognizable place contains the hallucination. A surreal building or landscape can qualify.

Do not use whenThe work contains only patterns, abstract tunnels, voids, or geometric chambers.

colour-shifting · Colour shifting

Use whenObjects in an external environment fluidly cycle through colours.

Do not use whenA closed-eye animation changes palette or the work is simply colourful.

colour-enhancement · Colour enhancement

Use whenExternal colours become visibly brighter or more vivid without changing identity.

Do not use whenThe palette cycles, splits into offsets, or loses saturation.

colour-suppression · Colour suppression

Use whenColours become darker, less saturated, or less distinguishable.

Do not use whenThe frame is dark because of lighting, grading, or source quality alone.

chromatic-aberration · Chromatic aberration

Use whenObject colours split into overlapping, spatially offset layers.

Do not use whenColours merely shift, intensify, or form a multicoloured edge.

visual-auras · Visual auras

Use whenAn open-eye halo or aura appears around an external object.

Do not use whenA painting uses glow, a luminous background, or closed-eye radiance.

transformations · Transformations

Use whenA specific external object visibly becomes another object or identity.

Do not use whenA static work is surreal or a closed-eye animation changes abstract form.

object-alteration · Deliriant-replication object alteration

Use whenA deliriant or DPH replication visibly supports the object-alteration convention.

Do not use whenA psychedelic replication merely drifts, warps, reorganizes, or recurses. Remove the tag unless Josie gives a row-specific override.

visual-twisting · Visual twisting

Use whenThe external field of view curls or spirals around a common center.

Do not use whenThe art contains a spiral or a closed-eye pattern rotates.

texture-liquidation · Texture liquidation

Use whenExternal textures simplify and smudge into a painted or cartoon-like surface.

Do not use whenThe source was already illustrated or low-detail.

visual-haze · Visual haze

Use whenThe surrounding air appears filled with imaginary smoke, fog, or haze.

Do not use whenThe image is only blurry or soft. Use acuity suppression when detail degrades.

visual-acuity-enhancement and visual-acuity-suppression

Use whenEnhancement sharpens external detail. Suppression degrades external detail into blur or indistinct edges.

Do not use whenThe editor applies ordinary focus, the source is low quality, or smoke-like haze causes the loss.

perspective-distortion · Perspective distortion

Use whenPerceived size or distance changes for the body, an object, or the environment.

Do not use whenThe camera zooms, the image warps, or the scene uses unusual perspective.

field-of-view-alteration · Field of view alteration

Use whenThe visible field expands, contracts, or takes on a fisheye-like shape.

Do not use whenDistances or object sizes change without a field-boundary change.

magnification · Magnification

Use whenDistant details appear enlarged and closer than their spatial position supports.

Do not use whenThe editor applies an ordinary zoom or crop.

increased-pareidolia · Increased pareidolia

Use whenA vague external stimulus resolves into a face, creature, or familiar form.

Do not use whenThe face or figure is explicitly drawn into the source.

recursion · Recursion

Use whenA section of the external scene repeats inside itself in a self-similar structure.

Do not use whenA clip loops or a motif repeats side by side.

tracers and after-images

Use whenTracers follow a moving object. After-images persist after the source disappears.

Do not use whenMotion blur, echo effects, or a static duplicate lacks temporal persistence.

auditory-distortion and auditory-hallucination

Use whenDistortion alters a sound source. Hallucination introduces a spontaneous or imagined sound.

Do not use whenThe file merely contains music or an audio stream.

machinescapes · Machinescapes

Use whenThe experience is a vast, intricate, hallucinatory mechanical landscape.

Do not use whenThe work contains machinery, circuitry, or biomechanical motifs without a landscape.

unspeakable-horrors · Unspeakable horrors

Use whenThe hallucinatory scenario is prolonged, disturbing, frightening, and fear-driven.

Do not use whenThe image is merely dark, grotesque, or unusual without that editorial framing.

07 · Scope boundaries

Keep row evidence, artist rules, and substance curation separate.

A reviewer can state all three in one note. They still target different data and require different checks.
