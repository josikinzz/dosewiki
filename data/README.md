# data/

Tracked datasets a third party can download and use without running the site. Everything here is loaded by source under `src/`, `lib/`, `server/`, or `scripts/` through the `@data/*` alias (TypeScript) or a relative path (`.mjs`). Generated build artifacts (`*.generated.json`, theme baselines, icon data, social-card manifests, route availability) stay beside their consumers; runtime configuration stays under `src/data/config/`; prompts and editorial copy live under `content/`.

`data/lineage.json` records every generated artifact in the repository with its role, producer, consumers, inputs, edit policy, and `refresh` object. `bun run provenance:check` validates it. It fails when a tracked `*.generated.*` file or a file matching `GENERATED_OUTPUT_GLOBS` or `AUTHORED_FILE_GLOBS` in `scripts/lib/data-artifact-lineage.mjs` has no entry, when a file named in `FILES_NEEDING_THEIR_OWN_ENTRY` there resolves only to a wildcard entry, or when a path-shaped consumer (a path with a slash, or a root file name such as `package.json`) no longer exists. An entry path without `*`, either an exact path or a `{a,b}` list, wins over a wildcard path that matches the same file. An authored or separately produced file inside a generated directory therefore gets its own entry and is listed in `FILES_NEEDING_THEIR_OWN_ENTRY`. A new producer that writes a tracked file outside the `*.generated.*` naming convention adds its output glob to `GENERATED_OUTPUT_GLOBS`. A new hand-edited file that gets an entry adds its path to `AUTHORED_FILE_GLOBS`, so removing that entry fails the check. Producer scripts write per-run sidecars into the gitignored `data/.lineage/` directory.

Each entry's `refresh` object says how its artifact is refreshed. With `"kind": "command"`, the one `command` regenerates the artifact, and optional `instructions` add caveats. With `"kind": "manual"`, no single command does. The required `instructions` say what a person does, `commands` lists the commands those steps use in order, and `runbook` names a `docs/` heading that holds an exact phased workflow. A command names a `package.json` script, as in `{ "script": "translate:ui", "args": ["--offline", "--write"] }`, run as `bun run <script> <args>`. Or it names a file, as in `{ "runtime": "node", "file": "scripts/replications/normalize-slugs.mjs" }`, run as `<runtime> <file> <args>`. An optional `env` object lists variables to set first. A value in angle brackets, such as `<postgres-read-url>`, is a placeholder. `bun run provenance:check` rejects an unknown kind or field, a script missing from `package.json`, a missing file, a runbook heading that does not exist, and the retired `refreshCommand` string. A listed command is not authorization. A production write still needs the ceremony in [data credentials](../docs/operations/data-credentials.md).

Licenses: datasets authored by dose.wiki are released under CC0 1.0 as described at `/docs/license` (section 3). Third-party datasets under `data/third-party/` carry their own terms, restated in the `LICENSE.md` beside each one and inventoried in the repository `NOTICE.md`. Records that describe people or creator-retained media are provenance records, not licensed content: the rights in the underlying artwork stay with the artist.
